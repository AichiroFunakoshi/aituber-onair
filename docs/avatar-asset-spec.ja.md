# PNGTuber Avatar Asset Spec

この文書は、`apps/tuber` の既存アバター画像を正式キャラクターへ
差し替えるための制作・検証条件を定めるものです。

## 基本方針

既存画像の絵柄や人物を踏襲する必要はありません。踏襲するのは、
アプリが前提としているキャンバス、構図、表示密度、4状態の整合性です。

キャラクターの顔と髪型を確定したあと、最初に
`mouth_close_eyes_open.png` をマスター画像として完成させます。残り3状態は
マスター画像全体を再生成せず、目と口だけを編集して作ります。

## 必須ファイル

`apps/tuber/public/avatar/` に、次の4ファイルを同名で配置します。

- `mouth_close_eyes_open.png`: 通常状態。口閉じ、目開き。
- `mouth_close_eyes_close.png`: まばたき。口閉じ、目閉じ。
- `mouth_open_eyes_open.png`: 発話状態。口開き、目開き。
- `mouth_open_eyes_close.png`: 発話中のまばたき。口開き、目閉じ。

通常状態はPWAのアイコンとApple Touch Iconにも使われています。小さく表示した際も、
顔、髪のシルエット、目元の特徴が判別できる構図にします。

## ファイル仕様

- 画像形式: PNG。
- キャンバス: 1024 x 1024 px。
- カラープロファイル: sRGB。
- カラーチャンネル: RGBA。
- 背景: 完全透過。背景色、影、縁取り用の四角形を入れない。
- 4枚すべてでキャンバスサイズ、解像度、色空間を一致させる。
- 文字、ロゴ、説明ラベルを入れない。

アプリでは画像を480 x 480 pxの正方形領域に `object-fit: contain` で表示します。
狭い画面では左右が見切れる可能性があるため、顔、目、涙ぼくろ、ピアスなどの
重要要素はキャンバス中央のおよそ70%以内に置きます。

## 構図

- 正面に近いバストアップ。
- 頭頂、髪、肩、衣装の下端までを1024 x 1024内に収める。
- 顔を主役にし、手、道具、大きな装飾を顔の前へ置かない。
- 頭部、顔、首、肩、衣装の位置を4状態で完全に固定する。
- 口パク時に顎、頬、鼻、首の位置を動かさない。
- まばたき時に眉、前髪、涙ぼくろ、耳、ピアスを動かさない。

## キャラクター同一性

正式な顔の基準は、管理用ワークスペースにある次の3ファイルです。

- `vtuber-icon-20260623-121150.png`
- `vtuber-face-identity-sheet-manual-base-20260630.png`
- `vtuber-face-direction-sheet-manual-base-20260630.png`

固定する特徴:

- 黒髪。
- 眉付近まである重めの前髪。
- 鎖骨より下、胸元より上で止まるミディアムロング。
- 青灰色の大きめの目。
- 淡い肌。
- 落ち着いた、少しミステリアスな表情。
- 涙ぼくろは片側だけ。
- 涙ぼくろがある側の見えている耳に複数のシルバーピアス。
- 反対側へ同じピアスを自動追加しない。
- 唇のピアスは入れない。

衣装、ヘッドドレス、メイド服、猫など、参考写真に含まれる一時的な要素は
キャラクターの固定要素にしません。

## 4状態の作り方

1. 通常状態をマスターとして確定する。
2. マスターを複製し、両目の開閉だけを編集する。
3. マスターを複製し、口の開閉だけを編集する。
4. 目閉じ版を複製し、口だけを開く。
5. 4枚を同じ位置で高速に切り替え、輪郭や衣装が揺れないことを確認する。

画像生成AIで4状態を別々に生成すると、顔、髪、衣装、線、色が少しずつ変わります。
4状態は別生成せず、同じマスターから局所編集で作成します。

## アプリへの差し替え

設定画面から選んだ画像は、ブラウザを開いている間だけの確認用です。
正式採用時は、4ファイルを `apps/tuber/public/avatar/` の既存ファイルと
同名で置き換えます。

差し替え後は、次を確認します。

- 通常表示で顔と髪型が読み取れる。
- 目開きと目閉じを切り替えても頭部が動かない。
- 口開きと口閉じを切り替えても顔の輪郭が動かない。
- 涙ぼくろとピアスが全状態で同じ位置に残る。
- 透過境界に白や黒の縁が出ない。
- macOS Safariの通常ウインドウと狭いウインドウで重要要素が見切れない。
- PWAアイコンとして縮小しても顔の印象が残る。
